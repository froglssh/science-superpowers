# 科學專題研究提案 (範例)

## 一、 研究題目
探討不同濃度的咖啡因溶液對綠豆 (Vigna radiata) 種子萌發率與幼苗根部生長之影響

## 二、 研究動機
在日常生活中，人們常使用咖啡渣作為植物肥料，認為其富含養分。然而，咖啡渣中含有高濃度的咖啡因 (Caffeine)。有些研究指出，咖啡因作為一種植物鹼，可能對某些植物具有生長抑制作用（化學他感作用，Allelopathy）。為了釐清咖啡因對植物幼苗早期發育的真實影響，我們決定以生長快速的綠豆作為模式植物，進行系統化定量研究。

## 三、 研究目的
1. 探討不同濃度咖啡因溶液對綠豆種子萌發率的影響。
2. 測量不同濃度咖啡因溶液對綠豆幼苗根部生長長度的影響。
3. 尋找可能抑制綠豆生長的咖啡因臨界濃度。

## 四、 研究問題
不同濃度（0 ppm、50 ppm、100 ppm、500 ppm、1000 ppm）的咖啡因溶液，對綠豆種子的萌發率（%）以及萌發第 5 天的根長（mm）有何影響？

## 五、 科學假說
* **假說**：隨著咖啡因濃度的升高，綠豆種子的萌發率會下降，且萌發後的幼苗根長會顯著變短，因為高濃度的咖啡因會抑制植物細胞的分裂與伸長。
* **預期結果**：0 ppm (對照組) 表現最佳，1000 ppm 組將受到嚴重的發育抑制。
