# 諾貝爾生醫獎學習單製作（教師版＋學生版）

本技能重現臺北市立麗山高中生物科林獻升老師 2020–2026 年「諾貝爾生醫獎」系列學習單的架構、題型與文風。老師提供當年度得獎資訊（新聞、官網新聞稿、科普文章、影片連結、AI 深度研究報告等）後，產出一份**教師版**與一份**學生版** Word 學習單，兩版題目與編號完全一致，學生版只是拿掉教師專用內容。

歷屆範本（老師的 Google 雲端「翰林新教案/諾貝爾生醫獎」資料夾）：
2020 C型肝炎病毒｜2021 辣椒素受體（TRPV1、Piezo）｜2022 古人類遺傳（帕博）｜2023 mRNA 疫苗（假尿嘧啶）｜2024 microRNA（lin-4/lin-14）｜2025 調節性T細胞與 FOXP3｜2026 光遺傳學（教學補充）。若連結了老師的電腦，可讀取同資料夾內舊檔對照風格。

## 步驟 0：先重構需求再動手

老師的偏好是：先依模型知識把原始要求**重構、擴寫、優化**成完整規格，再執行。開工前用 3–6 行列出「本次學習單規格」，包含：得獎年度與主題、三位得主與得獎理由、對應課綱章節、目標對象（普通班／資優班）、題數配置、要產出的檔案。規格清楚就直接執行，不必等老師確認。

只有下列情況才用一個問題詢問（可一次問完）：
- 目標對象不明且會大幅改變難度（普通班 vs 資優班）。
- 學生版要不要在文末附「解答與詳解」（2024、2025 有附，供自學；預設**不附**，另於教師版完整呈現）。
- 有沒有影片連結（有才做「影片時間軸」）。

## 步驟 1：蒐集與查核資料

1. **以老師提供的資料為主**，不足處用網路搜尋補齊，優先順序：
   nobelprize.org 新聞稿、Popular information、Advanced information（Scientific background）→ 卡羅林斯卡學院 → 中央社、泛科學、科學人等中文科普 → 原始論文摘要。
2. 必須查證、不可憑記憶寫的事實：得主姓名（中譯＋英文原名）、國籍、任職機構、得獎理由原文、宣布日期、關鍵論文年份與期刊、關鍵實驗的生物與方法、獎金。
3. 中文譯名各媒體不一時，採**中央社譯法**並在教師版註明。查不到或來源矛盾的細節，在教師版以「（待核對）」標註，不得自行編造數據或引言。
4. 整理一張「知識骨架」（內部用，不必輸出）：
   科學問題（過去的謎團／主流觀點）→ 得主的關鍵洞見 → 關鍵實驗（模式生物、技術、對照）→ 分子機制 → 為何被忽視或遭質疑 → 轉捩點證據 → 醫學應用 → 挑戰與限制 → 臺灣連結 → 遺珠與功勞分配。

## 步驟 2：找到「課本連結」與「主軸比喻」

**課本連結**：對應 108 課綱高中生物，寫成「選修生物一／三／四＋單元名」。歷屆用法：
- 選修生物一：細胞的分子、基因表現與調控、分子生物技術（cDNA、RNAi、PCR、西方墨點）
- 選修生物三：動物體的構造與功能（神經、感覺、人體防禦／免疫）
- 選修生物四：演化與多樣性
- 必修生物：細胞、遺傳、中心法則；探究與實作：假說、變因、對照、論證
各版本冊次略有差異，教師版提醒「請依貴校教科書核對」。

**主軸比喻**（老師文風的核心）：選一個貫穿全文的生活化比喻，並在題目中延續使用。歷屆範例：
- RNA 單股像「單身貴族」，容易突變（2020）
- 以抗體「釣」出病毒蛋白；辣椒素是尋找熱受體的「分子探針」（2020、2021）
- mRNA 是「傳令兵」（2023）
- 中心法則＝「圖書館餐廳」：DNA 是傳家食譜總匯、mRNA 是食譜影本、miRNA 是「出餐協調員」（2024）
- Treg 是免疫大軍的「維和部隊／憲兵」，FOXP3 是「主控開關、身份證」，自體免疫是「煞車失靈」（2025）

## 步驟 3：撰寫教師版

### 標頭（依序）
1. 第一行：`YYYY 諾貝爾生醫獎`
2. 主標題：吸睛、帶情緒或懸念，可用破折號、問句、雙關。範例：「揪出沉默的肝臟殺手——C型肝炎病毒的『前世今生』與幕後英雄」「尼安德塔人 DNA 你我都有？破解古人類的情慾流動 學習單」「mRNA技術與生醫邊緣人的逆襲 學習單」「深入探索基因調控的隱藏高手——微型RNA」。
3. 資源連結列（以「、」分隔，有才放，沒有的用【待補連結】）：介紹影片、網頁教學、網頁圖說、簡報教學、語音介紹、影片介紹、科普文章、測驗考卷／線上測驗。
4. 署名：`臺北市立麗山高中生物科林獻升老師使用（工具名）整理生成`（工具名照老師告知，未告知時寫 Claude）。

### 內文章節
**一、課程基本資訊**
- **適用章節**：條列對應的必修／選修單元。
- **學習內容**：條列 4–6 個核心概念，含專有名詞中英對照。
- **建議使用時機**：教完哪個單元後作為延伸素養教材；建議節數（例如 1–2 節：觀影、小組閱讀、論證與發表）。

**二、影片導讀與教學時間軸**（有影片才做）
影片名稱、連結、長度，加三欄表格：`時間軸｜影片章節主題｜教學引導與課堂提問重點`。每段寫一個可直接在課堂上問的問題。

**三、YYYY 諾貝爾生醫獎核心概念深化解析**
- 開場先從課本出發：「在你的高中生物課本中，我們學到了……」，再丟出課本解答不了的謎題。
- 得獎速覽（一段或小表）：得主（中譯＋原名）、機構、得獎理由、宣布日期。
- 3–5 個小節，標題要有畫面，如「(一) 跨越學科疆界：化學代理物理的『還原論』美學」「發現和平使者——調節性T細胞的誕生」「當天秤失衡——雙面刃」。
- 必含：科學家故事（坎坷、堅持、合作、意外）、關鍵實驗邏輯、分子機制、醫學應用與挑戰、總結。
- 有臺灣連結就寫（如郭勁宏博士、得主訪臺）；有遺珠就寫（諾貝爾獎最多三人），作為科學本質討論素材。

**四、核心概念圖解（教師背景知識）**
放 2–4 個 `【圖解建議】`，每個寫清楚圖名、要呈現的流程或對照、建議繪製方式（老師常用 NotebookLM、Gemini 生成資訊圖）。例：「TRPV1 開啟流程：辣椒素／>43°C → 構型改變 → Na⁺、Ca²⁺ 流入 → 去極化 → 動作電位 → 大腦解讀為『熱』」。

**五、深度思考與課堂討論**
- **（一）深度思考提問** 3–5 題，涵蓋：類比與思辨（延伸主軸比喻或自創比喻）、科學本質（為何被忽視、什麼證據翻轉）、技術與倫理、知識連結（與歷屆諾獎或相關技術比較）、創新挑戰（「如果你是頂尖科學家……」）。題首加【主題標籤】。
- **（二）連結課本，小組討論** 2–3 題：請學生翻課本對照，例如比較原核操縱組與 miRNA 調控、比較 TH／TC／Treg 並用軍隊比喻分工、判斷細胞療法屬於主動或被動免疫。
- 每題下方給 **參考答案**；開放題標「（開放性作答，鼓勵學生反思）」並列出引導方向。

**六、隨堂知識評量**
- **單選題 5 題**、**多選題 5 題**；選項 (A)–(E)（題目較簡單時可用 4 個選項），多選題寫「（應選 X 項）」，應選數分布在 2–4 項，不要每題都同樣數量。
- 題目由淺入深：擷取 → 理解 → 應用 → 推論。至少 2 題需要結合課本先備知識推理，不只是記內文。
- 干擾選項要「看似合理」：常見迷思（如 RNAi 抑制轉錄、K⁺ 外流造成去極化）、張冠李戴的得主貢獻、誇大的絕對化敘述（「完全」「絕對」「瞬間」）。
- 答案位置要分散，不要集中在同一個字母。
- 每題下方：**參考答案：(X)**，接著 **命題意圖與解析**：先一句說明評量什麼能力，再逐一說明每個錯誤選項錯在哪。

**七、探究與實作——科學研究**（素養題組，老師最重視的部分）
- 小標題：「探討：＿＿＿」，題名要有張力（如「尼安德塔人基因與 COVID-19 的死亡凝視」「新型癌症免疫藥物『抑Treg劑』的功效」）。
- 依序寫 **實驗背景** → **研究假說** → **實驗設計**（實驗對象、分組、對照組、觀測指標與技術：qPCR、西方墨點、流式細胞儀、鈣離子顯影、膜片箝制等）→ **實驗數據**（1–2 個表格，數字要合理且趨勢清楚）。
- 數據可以是依真實研究改編的**模擬數據**，必須在教師版註明「本題組數據為教學改編」。
- **探究問題** 4 題：(1) 單選：讀表判讀；(2) 多選：綜合推論（含「缺乏對照組」「相關≠因果」類陷阱）；(3) 非選：數據是否支持假說，引用數據說明；(4) 非選：批判思考、預測副作用或自行設計實驗（寫出實驗組、至少兩個對照組、預期結果）。
- 非選題給 **參考答案與評分規準**：總分、**滿分指標**（列出必須出現的關鍵詞或推理）、**部分給分**（常見不完整答案給幾分）。

**八、科學本質與生命教育討論**
1 個核心討論題，含「教師引導提問」與「討論關鍵點（教師總結指引）」。可選主題：基礎研究的價值、功勞分配與諾貝爾三人限制、典範轉移、科技倫理（記憶操控、基因檢測歧視、動物實驗 3R）。老師同時是生命教育教師，此節可連結生命教育課。

**參考資料**：列出實際用到的來源（官方新聞稿、科普文章、原始論文），附網址。

## 步驟 4：由教師版產生學生版

學生版＝教師版**刪除**以下內容，其餘文字、題目、選項、編號一字不改：
- 資源連結列中的「測驗考卷」（線上測驗可保留）
- 一、課程基本資訊；二、影片時間軸的「教學引導」欄（可保留影片連結與章節主題）
- 所有「參考答案」「命題意圖與解析」「評分規準」「教師總結指引」、「本題組數據為教學改編」註記、（待核對）標記
刪除後重新編章節號（例如教師版「三、核心概念深化解析」在學生版變成「一、」）。並加上作答空間：
- 單選、多選題號前加 `(　　)` 作答括號
- 非選題、討論題下方留 3–6 行作答線
- 頁首加「班級：＿＿ 座號：＿＿ 姓名：＿＿＿＿」
老師要求「學生版附解答」時，在文末加「解答與詳解」章節（2024、2025 格式），內容取自教師版。

## 步驟 5：文風規範

- 繁體中文、臺灣用語（臺北、臺灣、細胞介素、胞毒T細胞、核苷酸、轉譯）。
- 專有名詞首次出現：「中文（English, 縮寫）」，例：「調節性T細胞（Regulatory T cells, Treg）」。人名首次：「坂口志文（Shimon Sakaguchi）」。
- 關鍵概念用**粗體**；引號用「」，書名與期刊用《》；破折號用「——」。
- 語氣：對學生說話時用「你」，有溫度、帶故事性與畫面感，但科學敘述要精確，不誇大療效。
- 句子結構常見：先拋問題 →「答案藏在……」→ 解釋機制 → 回扣比喻。
- 化學符號正確：Na⁺、Ca²⁺、Cl⁻、3′ UTR、43°C。
- 不在題目或解析中出現與資料矛盾的數字。
