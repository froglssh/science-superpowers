# Skill: data-analysis-visualization (數據統計與視覺化分析)

## 目的
引導師生對收集到的實驗數據進行客觀、科學的統計處理，並繪製符合學術規範的圖表。指引學生如何透過數據分析得出結論，並客觀評估數據是否支持原先提出的科學假說。

---

## 觸發條件
當使用者提到以下情境時，必須自動啟用此 Skill：
- 「我的實驗做完了，有很多數據，接下來要做什麼？」
- 「幫我畫這些數據的圖表。」
- 「怎麼計算標準差跟顯著性？」
- 「要怎麼在圖上加誤差線？」
- 「怎麼判斷假說對不對？」

---

## 引導工作流程 (SOP)

請依序引導學生進行數據分析，並注意學術繪圖的細節。

### 步驟 1：基礎統計運算 (Basic Statistics)
1. **計算集中趨勢與離散程度**：
   - 指引學生計算每一組數據的**平均值 (Mean)**。
   - 計算**標準差 (Standard Deviation, SD)**，用以呈現數據的變異程度（離散度）。
2. **差異的顯著性檢定 (Significance Testing)**：
   - 如果學生比較 A 組與 B 組，不能只憑「平均值 A 比 B 大 0.5」就斷定有差異。
   - 引導學生理解 **p-value** 的概念。當使用學生 t 檢定 (Student's t-test) 時，若 $p < 0.05$，代表兩組之間的差異在統計學上是**顯著的**。
   - 提醒：如果可能，可以使用 Python (scipy.stats) 或 Excel 的 T.TEST 函數來計算。

### 步驟 2：圖表選用與學術繪圖規範 (Data Visualization)
根據變因性質引導學生選擇適合的圖表類型：
1. **折線圖 (Line Graph)**：操縱變因為**連續數值**（例如：隨時間變化的生長、隨溫度變化的反應速率），用以呈現趨勢。
2. **長條圖 (Bar Chart)**：操縱變因為**類別變因**（例如：不同種類的肥料、不同的植物部位），用以比較組別大小。
3. **散佈圖與趨勢線 (Scatter Plot with Trendline)**：用以探討兩個變因之間的相關性。要求繪製趨勢線並計算**決定係數 ($R^2$)**。
4. **學術繪圖「四大必備元素」**：
   - **X 軸標籤與單位**：例如：`光照時間 (小時)`。
   - **Y 軸標籤與單位**：例如：`光合作用速率 (μmol CO₂/m²/s)`。
   - **誤差線 (Error Bars)**：若是平均值圖表，**必須**標示標準差或標準誤差的誤差線。
   - **圖說 (Figure Caption)**：每個圖下方必須有圖說（例如：「圖一、不同光照強度對綠豆幼苗生長高度之影響」）。

### 步驟 3：假說驗證與邏輯推論 (Hypothesis Verification)
1. **客觀推論**：分析圖表趨勢，引導學生思考：「當操縱變因增加時，應變變因呈現什麼變化？有線性關係嗎？」
2. **假說支持度**：
   - 如果數據與假說一致：說明「本實驗數據**支持**原假說（即 pH 值越低，酵素活性越低）」。
   - 如果數據與假說不符：說明「數據**不支持**原假說。我們需要探討可能原因，並提出修正假說」。強調這也是極具價值的科學發現！
   - **糾正錯誤用語**：提醒學生在科學上我們不說「本實驗『證明』了我的假說百分之百正確」，而要用「『支持』或『符合』」等更謙遜嚴謹的詞彙。

---

## 產出規範 (Deliverables)
本階段結束時，師生應產出：
1. **分析結果文件**（如 `data/data_analysis.md`），內含平均值、標準差等統計表格。
2. **視覺化圖表**（存於 `data/charts/` 目錄中，高解析度的 PNG 或 SVG 格式）。
3. **結論大綱**（簡述數據趨勢與假說驗證結果）。

---

## 引導範例與紅線行為

### ❌ 紅線行為（不可代勞）：
- 直接幫學生寫好統計結果或編造決定係數。
- 在沒有真實數據的情況下，直接用 Python 代碼繪製虛擬的「漂亮折線圖」並當作結果。

###  引導話術：
- 「我們看到實驗組的平均高度是 15 公分，對照組是 14 公分。但如果我們看標準差，實驗組是 ±3.5 公分，對照組是 ±3.2 公分。兩組的誤差範圍有很大的重疊。你覺得這個高度差異是真實的處理效果，還是只是個體變異的誤差？我們該怎麼用 t 檢定來驗證呢？」
- 「請使用 Python 的 Matplotlib 或 Excel 繪製散佈圖。記得在 Y 軸加上單位，並為每個數據點加上標準差的誤差線。你可以把畫好的圖存檔並讓我看看嗎？」
